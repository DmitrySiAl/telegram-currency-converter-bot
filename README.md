Мультиязычный бот-конвертер валют

Это простой телеграм-бот для конвертации валют, написанный на Python с использованием библиотеки aiogram 3. Бот умеет определять язык пользователя, сохранять настройки в базу данных и позволяет настраивать список избранных валют для быстрого просмотра.

Что он умеет:
* Автоматически подстраивает язык: При первом запуске бот смотрит на язык интерфейса твоего Телеграма (русский, английский или немецкий) и сразу начинает общаться на нем. Язык также можно изменить вручную через меню.
* Быстрая конвертация
* Удобное избранное: Нажимаешь кнопку «Избранные курсы», открывается меню с инлайн-кнопками. Кликаешь по валютам, рядом с ними загораются галочки, и они сразу добавляются в твой личный список.
* Помнит всё: Благодаря базе данных, бот не забудет твой язык и выбранные валюты, даже если его перезапустить.

Технологии внутри:
* Python 3.10+
* Aiogram 3.x 
* SQLAlchemy 2.0 + aiosqlite 

Как запустить проект у себя:

1. Клонируй репозиторий:
```bash
git clone https://github.com
cd ИМЯ_РЕПОЗИТОРИЯ
```

2. Создай и активируй виртуальное окружение:
```bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для Linux/macOS:
source venv/bin/activate
```

3. Установи зависимости:
```bash
pip install -r requirements.txt
```

4. Создай файл конфигурации:
Рядом с `main.py` создай файл с именем `.env` и вставь туда токен своего бота, который ты получил у @BotFather:
```text
BOT_TOKEN=тут_твой_токен_бота
```

5. Запусти бота:
```bash
python main.py
```
